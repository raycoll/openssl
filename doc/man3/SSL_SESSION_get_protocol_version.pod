=head1 NAME

SSL_SESSION_get_protocol_version,
SSL_SESSION_set_protocol_version,
SSL_SESSION_get_learned_group_id
- get and set the session protocol version, get the learned key share group

=head1 SYNOPSIS

 #include <openssl/ssl.h>

 int SSL_SESSION_get_protocol_version(const SSL_SESSION *s);
 int SSL_SESSION_set_protocol_version(SSL_SESSION *s, int version);
 unsigned int SSL_SESSION_get_learned_group_id(const SSL_SESSION *s);

=head1 DESCRIPTION

SSL_SESSION_get_protocol_version() returns the protocol version number used
by session B<s>.

SSL_SESSION_set_protocol_version() sets the protocol version associated with the
SSL_SESSION object B<s> to the value B<version>. This value should be a version
constant such as B<TLS1_3_VERSION> etc. For example, this could be used to set
up a session based PSK (see L<SSL_CTX_set_psk_use_session_callback(3)>).

SSL_SESSION_get_learned_group_id() returns the TLS key agreement group, as
its IANA registered identifier (for example 24 for B<secp384r1> or 29 for
B<x25519>), that a TLSv1.3 client learned from the completed handshake that
produced session B<s>, when key share learning (B<SSL_OP_KEYSHARE_LEARNING>,
see L<SSL_CTX_set_options(3)>) is enabled: the group negotiated in that
handshake.  The client predicts a key share for this group when the session
is reused before it expires.
L<SSL_group_to_name(3)> can be used to obtain a printable name.

=head1 RETURN VALUES

SSL_SESSION_get_protocol_version() returns a number indicating the protocol
version used for the session; this number matches the constants I<e.g.>
B<TLS1_VERSION>, B<TLS1_2_VERSION> or B<TLS1_3_VERSION>.

Note that the SSL_SESSION_get_protocol_version() function
does B<not> perform a null check on the provided session B<s> pointer.

SSL_SESSION_set_protocol_version() returns 1 on success or 0 on failure.

SSL_SESSION_get_learned_group_id() returns the learned group identifier, or 0
if nothing was learned.
